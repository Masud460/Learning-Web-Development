9. React components are pure functions of their props and state — they should only return UI.
If we put side effects directly in the body of a component, they would run every render and could cause unexpected problems.
useEffect lets us:

    1. Control when side effects run (only on mount, on specific state changes(It means page reload etc.), or on every render).

    2. Automatically clean up effects when the component unmounts or dependencies change.

11. The useRef hook used to give reference of selected components in our page so that functions can be performed on referenced values.

12. Using method of useRef:
    1st:
        create a variable and store the useRef to it, and if you don't need any default value, than put null value to it;
        like this: let passwordRef = useRef(null)

    2nd:
        Determine which input value's reference do you need, and set the reference value to that input field like this:
             <input ref={passwordRef}>

    3rd:
        Use the reference with the variable name like this:
            passwordRef.current?.select() // for selecting the text.
            passwordRef.current?.setSelectionRange(0, 8) // for set selection range.
