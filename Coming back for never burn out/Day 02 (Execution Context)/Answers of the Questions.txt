5. There are two execution contexts in JS, 1: Global Execution Context. 2: Function Execution Context.

6. Every time we create a new JS file the first thing happens to it that is creation of Global Execution Context. and there are some objects like window, this, variable object and scope chain etc. This is the loading phase of Global Execution Context.

7. When we create a variable it goes to the global execution context and JS allocates it(The variable) by it's name and the value is 'undefined' if the variable created by var keyword. And when we create a function in JS it goes to the global execution context and JS allocates it by its name with its body as a value. The whole process also known as Loading Phase or Creation Phase.

8. After the creation phase, the compiler starts Execution Phase. It looks at the created variables and functions and defines their values.

9. Every time we invoke a function a new Execution Context will be created, it has all things those are in Global Execution Context except the Global Object, cause it stays in the global object. Instead, it has an object called parameter object or argument object. It also has the two phases, 1. Memory Creation Phase and 2. Execution Phase.

10. JS has a stack feature called call stack. It maintances every context up to another.
