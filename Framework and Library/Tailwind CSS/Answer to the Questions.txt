1. Type the command on terminal:
    npm init -y
    npm install -D tailwindcss@3 postcss autoprefixer vite;
    then type the command: npx tailwindcss init -p; then type a '*' with qoutetion in tailwind.config.js content area, then add ("scripts": {
    "start": "vite"
  }) in package.json file, and type these three things in input.css file (@tailwind base;
  @tailwind components;
  @tailwind utilities); 
  then run the command: npm run start;
