🚫 What You Should NEVER Do Again

❌ Never attach event listeners:

1. Inside a function that runs multiple times

2. Inside loops over dynamic elements

.3 After querySelectorAll() repeatedly

❌ Never do this pattern:

elements.forEach(el => {
  el.addEventListener(...)
});
inside dynamic DOM creation




Golden Rule:
1. Create element → attach listener ONCE
OR
2. Use event delegation on parent
