4. When we need to repeat a single section(like a card item) in UI and the outer things should be same, we can do it like this:
 1st: Get the list of different data (some different data's card) as an array.
 2nd: Create a component that same for all cards.
 3rd: Go to the section in UI and write js in jsx with these brackets "{}", then use map method with the data array in these brackets. and don't forget to use 'key' property like this:
    {courses.map(course => {
        return <CourseCard 
            key={course.id}
            src={course.src}
            courseTitle={course.title}
            courseDescrip={course.courseDiscription}
            enroll={course.enrolled}
        />
    })}

7. In normal block layout, a child element does not automatically take the full height of its parent; it only grows based on its content. Height in CSS does not inherit by default. When the parent is converted into a flex container, the child becomes a flex item, and flexbox allows space distribution. By applying flex-grow (or flex-1 in Tailwind), the child is instructed to take up the remaining available space. That's why the child fills the entire height only when flexbox is used properly.
