10. 
1. Create a new component (e.g. User.jsx).

2. In your router, define a path with a route parameter using a colon (:). Example:

<Route path="user/:userId" element={<User />} />
Here, :userId is the dynamic part of the URL.

3. Inside your component, import and use the useParams hook from react-router-dom.

4. Destructure the param (same name you used after the colon) and use it in your JSX.

Example:

// User.jsx
import { useParams } from "react-router-dom";

export default function User() {
  const { userId } = useParams(); // userId matches ":userId" in the route

  return (
    <h1>User: {userId}</h1>
  );
}

12. To solve this, we can use the loader prop in the Route component. The loader allows us to fetch the required data before rendering the component. Here’s how to do it:

1. Create a method that fetches data from the API and returns it.
2. Use the useLoaderData hook inside the component to access that data.
3. Pass the method to the Route via the loader prop.

Example:
Route:

<Route
  path="github"
  element={<Github />}
  loader={githubInfoLoader}
/>

Component:
import { useLoaderData } from "react-router-dom";

export default function Github() {
  const data = useLoaderData();
  return (
    <div className="flex flex-col justify-center items-center text-white bg-gray-700 text-3xl m-4 p-4">
      <h1 className="block">Github Followers: {data.followers}</h1>
      <img className="m-4" width={250} src={data.avatar_url} alt="github img" />
    </div>
  );
}


Loader function:
export const githubInfoLoader = async () => {
  const res = await fetch("https://api.github.com/users/hiteshchoudhary");
  return res.json();
};

Using the loader prop allows us to fetch the data before the component renders, so the component receives the data instantly via useLoaderData. This removes the delay and makes the navigation feel faster.
