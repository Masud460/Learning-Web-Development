Q: What is event delegation?
A: Event Delegation is a function that helps us to control many same element and repeated element's listener works from thier parent element instead of using the listener in every element.

Q: When to use event delegation?
A: Use it when:
1. Elements are dynamic
2. Elements are added/removed
3. Many similar elements exist (lists, tables, cards)
4. You faced duplicate event bugs (like before)

Q: When not to use it?
A: Avoid if:
1. The element exists only once
2. The event should NOT bubble (e.g. focus, blur)
3. You truly need separate listeners (rare)
